# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) (v2.1).

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, caste, color, religion, or sexual identity and orientation.

## Enforcement

Report unacceptable behavior via a **private GitHub Security Advisory** or by contacting the repository maintainers through GitHub. Do not post enforcement requests as public issues if they involve individuals.

Maintainers will review and respond as they are able. Consequences may include a warning, temporary ban, or permanent ban from the project, following the Contributor Covenant impact guidelines.
