# MCP host configs

Snippets for hosts that **spawn** `vectorsmith serve`. Replace `/absolute/path` and ensure `vectorsmith` is on that host's `PATH`.

| File | Host |
|---|---|
| [`claude_desktop.json`](claude_desktop.json) | Claude Desktop (`claude_desktop_config.json`) |
| [`claude_code.mcp.json`](claude_code.mcp.json) | Claude Code project (`.mcp.json`) |
| [`codex.config.toml`](codex.config.toml) | Codex (`~/.codex/config.toml` or `.codex/config.toml`) |
| [`cursor.mcp.json`](cursor.mcp.json) | Cursor (`.cursor/mcp.json`) |
